# Profil-avatarer

Legg en bildefil her med **samme navn som spiller-IDen**, så får profilen sin egen avatar.
Mangler filen, faller appen tilbake til initialer + farge.

## Spiller-IDer

| Fil-navn (uten endelse) | Profil |
|-------------------------|--------|
| `alf`                   | Alf Kåre |
| `anders`                | Anders |
| `danny`                 | Danny |
| `fredrik`               | Fredrik |
| `ruben`                 | Glenn Ruben |
| `jorgen`                | Jørgen |
| `steinar`               | Steinar |
| `sverre`                | Sverre |
| `vegard`                | Vegard |

## Eksempel

`public/avatars/vegard.png` → Vegard sin profil bruker det bildet.

## Format

- Støtter `.png .jpg .jpeg .webp .avif .gif .svg`
- Kvadratisk bilde anbefales (vises i en sirkel), f.eks. 400×400 px
- Små bokstaver i filnavnet, ingen mellomrom
